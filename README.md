# Gender Classifier

A machine learning web app that predicts gender based on input features.

## Live Demo
[Open App](https://gender-classifier-8epg3m5xhpxk2knb92x3su.streamlit.app/)

## Dataset
- 5000+ rows of gender classification data

## Tech Stack
- Python
- scikit-learn
- Streamlit
- pandas, numpy

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
